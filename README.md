# Jale.pe

Marketplace peruano que conecta estudiantes universitarios y recién egresados con MYPES que necesitan diseño, web, marketing, administración e idiomas. El pago se retiene en escrow hasta que el cliente aprueba el trabajo.

## Prototipo UI

```bash
npm install
npm run dev
```

- Landing: `/`
- Sistema de diseño: `/sistema-de-diseno`
- Onboarding estudiante: `/onboarding`
- Explorar (cliente sin registro): `/explorar`
